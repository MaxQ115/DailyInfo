# DailyInfo 每日快讯 7×24

全天候 7×24 小时财经电报与市场要闻移动端微应用（Mobile First）。

## ✨ 功能亮点

- 📱 **移动端优先（Mobile First）**：专为手机视口精心设计，排版紧凑清晰，单手操作顺手；在 PC 端自适应居中呈现精致终端。
- 📑 **顶部 Tab 预留扩展**：
  - 当前聚焦：`【财联社 7×24】`
  - 预留可扩展 Tab：`【全网要闻】`、`【全球市场】`、`【行业追踪】`（在 `js/app.js` 的 `CONFIG.tabs` 中随时增删）。
- ⏱️ **高可读性时间轴流**：
  - 亮蓝时间戳高亮（如 `15:04`、`15:02`）
  - 标题粗体中括号提炼加粗
  - 紧随正文舒适行高排版，虚线清晰分割
  - 重点焦点电报智能微标签
- ⚡ **毫秒级实时电报流**：
  - 首屏 0 秒瞬间渲染（零白屏、零加载等待）
  - 支持后台 30 秒自动轮询拉取最新电报
  - 手动下拉/点击右上角刷新
- 🔍 **即时搜索与过滤**：
  - 支持关键词实时高亮筛选（如搜“ETF”、“降息”、“茅台”、“芯片”等）
  - 快捷标签一键过滤
- 📋 **实用微功能**：
  - 一键复制单条快讯
  - `A/A+` 字号大小随心切换
  - 平滑回到顶部
